# Cluaupp schemas

VS Code / Cursor language support for Cluaupp live schemas.

Installed by `cluaupp intellisense` into `~/.cursor/extensions` and `~/.vscode/extensions`.

## Languages

| Ext | Highlight | Completions |
| --- | --- | --- |
| `.flare` | packets / queries | Flare IntelliSense (hover, diagnostics, outline) |
| `.hive` | components | snippets |
| `.mint` | formatters | snippets |
| `.bloom` | presets | snippets |
| `.helm` | commands | snippets |
| `.shift` | states / transitions | snippets |
| `.axiom` | groups | snippets |

CL++ (`.clpp` / `.clp` / `.clh`) highlighting still comes from `clpp setup`.
