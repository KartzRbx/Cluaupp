```
cluaupp <command> [folder]
```

Cluaupp orchestrates **CL++ 0.8.x → Luau** and owns the **Roblox Target** (API Registry). It does not parse the language. `clpp` compiles each `.clpp` / `.clp` / `.clh`; Cluaupp post-processes and writes `out/`.

<Aside type="caution">
Need CL++ **0.8.0+** for Option/Result and canonical `import` (host floor still **0.7.0+**). A cargo `clpp 0.1.0` earlier on PATH cannot parse modern CL++. Run `cluaupp language`. Override with `CLPP` / `CLPP_PATH`.
</Aside>

## `cluaupp init [folder]`

Creates a Roblox service tree under `src/` (`ReplicatedStorage/Shared`, `ServerScriptService`, `StarterPlayer`, `ServerStorage`, `ReplicatedFirst`), Rojo, `rokit.toml`, and a CL++ scaffold. Needs Cluaupp **1.4.0+**. Then run `clpp setup` for CL++ IntelliSense. `.flare` files use the Flare extension from `cluaupp intellisense`.

## `cluaupp build [folder]`

Compiles `src/**/*.{clpp,clp,clh}` into `out/`. One tagged file becomes one Luau instance.

```bash
cluaupp build
cluaupp build --format --analyze
cluaupp build --frozen
cluaupp build --no-incremental -j 4
cluaupp build --input ./src/ServerScriptService/Boot/DataBoot.server.clpp --output ./out/ServerScriptService/Boot/DataBoot.server.luau
```

`--format` runs StyLua; `--analyze` runs `luau-analyze`. `--frozen` fails on API lock / Flare version / component contract drift. Incremental compile cache lives under `.cluaupp/compile-cache` (disable with `--no-incremental`). `-j/--jobs` sets parallel transpile workers on the async path (`CLUAUPP_JOBS` env also works).

If `clpp` is missing: install [CL++ 0.8.0+](https://github.com/KartzRbx/CLPP/releases) or set `CLPP` / `CLPP_PATH`.

## `cluaupp watch [folder]`

Rebuilds on save (async `clpp api compile`). Does not write `out/` while compile fails.

## `cluaupp optimize` / `profile` / `docs` / `security` / `analyze` / `check-authority`

```bash
cluaupp optimize              # advisor JSON
cluaupp optimize --profile    # rank with cluaupp.profile.json
cluaupp optimize --apply      # insert #pragma native on numeric-hot fns
cluaupp optimize --apply --layout          # + #pragma layout soa + *Soa.luau
cluaupp optimize --apply --layout --buffer # pack f32/i32 columns into buffer
cluaupp profile               # write cluaupp.profile.json template
cluaupp profile --ingest hits.jsonl   # merge Studio/playtest PGO events
cluaupp bridge                # Studio↔IDE HTTP bridge (:3847)
cluaupp docs                  # .cluaupp/PROJECT.md
cluaupp security
cluaupp check-authority       # AUTH* + call-graph AUTH004
cluaupp analyze               # alias of target doctor
```

Emitted Luau gets `-- cluaupp-source: …`. With `#pragma native` in CL++, emit also gets `--!native`. Studio: `plugins/CluauppNav` (debug panel + Open IDE). Keep `cluaupp bridge` running and enable HttpService.

## `cluaupp language`

Prints the selected `clpp` binary + version, skipped older installs, and `clpp api manifest`. Needs CL++ **0.7.0+** (prefer **0.8+**).

## `cluaupp intellisense` / `cluaupp lsp`

Installs the **Flare** editor extension (`.flare` highlighting, completions, hover, diagnostics) and writes `files.associations`. Then runs `clpp setup` for CL++. `cluaupp lsp` is the Flare language server on stdio.

## `cluaupp api …`

Roblox API registry (Cluaupp target):

```bash
cluaupp api generate
cluaupp api verify
cluaupp api coverage
cluaupp api inspect Players
cluaupp api search PlayerAdded
cluaupp api diff api/snapshots/latest.profile.json
cluaupp api aux-diff path/to/@rbxts/types   # optional coverage only
```

Reuse-first: Cluaupp supplies registry + `lsp-index.json`. CL++ IntelliSense is the **CLPP** Language Server — not a Cluaupp Roblox IDE.

## `cluaupp target …`

```bash
cluaupp target info
cluaupp target doctor
cluaupp target capabilities
cluaupp target check-context path/to/file.server.clpp
cluaupp target lock
```
