# Roblox API reference

Official documentation: [create.roblox.com/docs](https://create.roblox.com/docs).

Cluaupp **does not** mirror Creator Docs. Browse the registry:

```bash
cluaupp api search Player
cluaupp api inspect Players
cluaupp api coverage
```

CL++ Language Server metadata: `api/generated/lsp-index.json` (see [LSP metadata](../../architecture/lsp-metadata/)).

CL++ header projections: `include/clpp/generated/` and `include/clpp/datatypes.clh`.
