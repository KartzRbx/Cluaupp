# CL++ agent skills

Cursor skills that teach the agent how to write CL++ and Cluaupp schemas.

`cluaupp init` copies this folder to `.cursor/skills/` in the game.

| Skill | When |
| --- | --- |
| `clpp-language` | `.clpp` / `.clh` / schemas, compile, accessors |
| `clpp-style` | professional layout, named callbacks, no leftover diagnostics |
| `clpp-hive-flare` | Hive ECS + Flare packets, server authority |

CL++ highlighting still comes from `clpp setup`. Schema highlighting (`.hive`, `.flare`, …) comes from `cluaupp intellisense`.
