Engine value types. In C++ you construct with Vector3(x,y,z); Cluaupp emits Vector3.new.

Vector3

2D point or direction. Luau: Vector2.new(x, y). Vector3int16
Vector3 with 16-bit integers. Vector2int16
Vector2 with 16-bit integers. CFrame
3D position + rotation. Luau: CFrame.new(...) / CFrame.lookAt(...). UDim
1D scale + offset (GUI). Luau: UDim.new(scale, offset). UDim2
2D scale + offset (GUI). Luau: UDim2.new / UDim2.fromScale / UDim2.fromOffset. Color3
RGB color 0–1. Luau: Color3.new / Color3.fromRGB / Color3.fromHSV / Color3.fromHex. BrickColor
Named Roblox color. BrickColor.new(name) or BrickColor.new(r,g,b). Rect
2D rectangle. Rect.new(min, max) or Rect.new(x0,y0,x1,y1). Ray
3D ray. Ray.new(origin, direction). RaycastParams
Filters for WorldRoot:Raycast. RaycastResult

Filters for GetPartBoundsInBox / GetPartsInPart. NumberRange
