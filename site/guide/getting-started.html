Getting started

Cluaupp is the definitive merge of C++ and modern Luau (--!strict, local, const) with first-class Roblox APIs.

Install

npm install -g cluaupp
cluaupp init my-game
cd my-game
cluaupp build
rojo serve

Datatypes in C++

#include <cluaupp/roblox.hpp>

void init() {
  auto* part = new Part(workspace);
  part->Name = "Platform";
  part->Size = Vector3(8, 1, 8);
  part->Position = Vector3(0, 10, 0);
  part->CFrame = CFrame::lookAt(Vector3(0, 10, 0), Vector3(0, 10, -10));
  part->Anchored = true;
  part->BrickColor = BrickColor("Bright red");
  part->Color = Color3::fromRGB(255, 0, 0);

  auto* gui = new ScreenGui(GetService<Players>()->LocalPlayer->FindFirstChild("PlayerGui"));
  auto* frame = new Frame(gui);
  frame->Size = UDim2::fromScale(1, 1);
  frame->Position = UDim2(0, 0, 0, 0);
}

This becomes Vector3.new, CFrame.lookAt, UDim2.fromScale, Color3.fromRGB, and Instance.new("Part").
